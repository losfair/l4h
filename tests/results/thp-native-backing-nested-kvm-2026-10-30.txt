Method:
  Same kernel and backing allocator, MADV_NOHUGEPAGE versus MADV_HUGEPAGE.
  Fresh process per mode/trial, alternating order, trial 0 excluded as warmup.
  Five measured trials per mode; no CPU affinity pinning.
  THP/defrag explicitly set to madvise; shrink_underused=0;
  khugepaged scan_sleep_millisecs=600000 to isolate fault-time allocation.
  Dense: write one byte per 4 KiB over an aligned 64 MiB mapping.
  Random: 1,000,000 deterministic LCG page-stride reads in that mapping.
  Fork: average of eight fork/exit/wait operations after populating it.
  COW: fork, child writes every 4 KiB, verifies, exits, parent waits.
  Protect: make one 4 KiB page read-only then writable in each of 32 PMDs.
  Unmap: release that mapping after the protection/split phase.
  Sparse: write one 4 KiB page per 2 MiB in a fresh 64 MiB mapping.
  Huge coverage and COW data integrity are asserted.
  The test module independently reports native seL4 large leaves: exactly
  32 for dense THP trials, zero for base-page trials, also asserted.
  VmPTE includes the seL4 mapping/object charge plus Linux page tables.
  The kernel direct map retains 4 KiB aliases. Only process mappings in
  this test use native large leaves. Host-created boot RAM uses fallback.
